Complaint Sentiment Analysis & NLP EDA
Overview

This project focuses on performing Exploratory Data Analysis (EDA) and text preprocessing on Reddit comments for sentiment analysis using Natural Language Processing (NLP).

The main objective is to clean, analyze, and understand textual data before building machine learning or deep learning sentiment classification models.

The project includes:

Data cleaning
NLP preprocessing
Statistical text analysis
Visualization
N-gram analysis
Word frequency analysis
Word cloud generation
Sentiment distribution analysis

The dataset contains Reddit comments labeled into:

Positive (1)
Neutral (0)
Negative (-1)
